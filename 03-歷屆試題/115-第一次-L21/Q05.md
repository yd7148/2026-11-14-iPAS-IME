# 115-1-L21-Q05

## 題目

下列何者不屬於資料探勘（Data Mining）常用的軟體工具？

- (A) SQL server
- (B) C#
- (C) Oracle
- (D) CSV

## 官方答案

**D**

## 解題


### 判斷關鍵

題目要求找出正確或最合適的敘述。官方答案為 **D**，其選項內容為：「CSV」。

- **資料分析**：資料分析流程通常包含蒐集、清理、整合、轉換、建模與應用。資料探勘從資料找出模式或預測，與單純感測、檔案格式或資料輸入並不相同。



### 選項核對

| 選項 | 內容 | 判定 |
|:---:|---|---|
| A | SQL server | 非官方正解；以判斷關鍵逐項排除 |
| B | C# | 非官方正解；以判斷關鍵逐項排除 |
| C | Oracle | 非官方正解；以判斷關鍵逐項排除 |
| D | CSV | 官方正解 |

> [!tip] 複習提示
> 先辨識題目問的是「正確」還是「不正確」，再用上面的核心定義排除干擾選項。
