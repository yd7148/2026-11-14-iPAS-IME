# 115-1-L21-Q34

## 題目

在以生產管理大數據推動智慧製造（Smart Manufacturing）的發展方向中，下列何 者不屬於核心推動重點？

- (A) 將問題的產生過程利用資料進行分析、模組化和管理，從解決可見的問題到避 免可見的問題
- (B) 從資料中挖掘隱性問題的線索，透過對隱性問題的預測分析，在其發展成為顯 性問題之前進行解決
- (C) 利用逆向工程，利用知識對整個生產流程進行剖析和精細模組化，從產品設計 和製造系統設計中避免問題
- (D) 收集統計良率的資料後，建立生產效率估計，以供設備數量需求之參考依據

## 官方答案

**D**

## 解題


### 判斷關鍵

題目要求找出正確或最合適的敘述。官方答案為 **D**，其選項內容為：「收集統計良率的資料後，建立生產效率估計，以供設備數量需求之參考依據」。

- **品質管理**：品質管理不是只靠終檢，而是從設計、製程到數據監控預防缺陷。FMEA 的 RPN 通常由嚴重度、發生度與偵測度構成；管制圖則用中心線與管制界限判讀製程是否出現特殊原因。

- **資料分析**：資料分析流程通常包含蒐集、清理、整合、轉換、建模與應用。資料探勘從資料找出模式或預測，與單純感測、檔案格式或資料輸入並不相同。



### 選項核對

| 選項 | 內容 | 判定 |
|:---:|---|---|
| A | 將問題的產生過程利用資料進行分析、模組化和管理，從解決可見的問題到避 免可見的問題 | 非官方正解；以判斷關鍵逐項排除 |
| B | 從資料中挖掘隱性問題的線索，透過對隱性問題的預測分析，在其發展成為顯 性問題之前進行解決 | 非官方正解；以判斷關鍵逐項排除 |
| C | 利用逆向工程，利用知識對整個生產流程進行剖析和精細模組化，從產品設計 和製造系統設計中避免問題 | 非官方正解；以判斷關鍵逐項排除 |
| D | 收集統計良率的資料後，建立生產效率估計，以供設備數量需求之參考依據 | 官方正解 |
