# 115-1-L22-Q05

## 題目

下列何者並非常用的數據資料交換格式？

- (A) INI
- (B) JSON
- (C) XML
- (D) BMP

## 官方答案

**D**

## 解題


### 判斷關鍵

題目要求找出正確或最合適的敘述。官方答案為 **D**，其選項內容為：「BMP」。

- **資料分析**：資料分析流程通常包含蒐集、清理、整合、轉換、建模與應用。資料探勘從資料找出模式或預測，與單純感測、檔案格式或資料輸入並不相同。

- **工業通訊**：工業通訊題先辨識協定、傳輸介面與資料格式。MQTT QoS 僅定義 0、1、2 三級；TCP/IP 需要可路由的位址設定，RS-232 則是串列傳輸介面。



### 選項核對

| 選項 | 內容 | 判定 |
|:---:|---|---|
| A | INI | 非官方正解；以判斷關鍵逐項排除 |
| B | JSON | 非官方正解；以判斷關鍵逐項排除 |
| C | XML | 非官方正解；以判斷關鍵逐項排除 |
| D | BMP | 官方正解 |

> [!tip] 複習提示
> 先辨識題目問的是「正確」還是「不正確」，再用上面的核心定義排除干擾選項。
